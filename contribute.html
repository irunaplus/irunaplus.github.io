📝 ช่วยเพิ่ม / แก้ไขข้อมูลอาชีพ

กรอกข้อมูลง่ายๆ ผ่านแบบฟอร์ม ไม่ต้องเขียนโค้ด JSON — ส่งให้แอดมินตรวจสอบและอนุมัติขึ้นเว็บอัตโนมัติ

1. เลือกอาชีพ & กรอกฟอร์มสกิลจากอาชีพก่อนหน้าจะสืบทอดมาให้อัตโนมัติ ไม่ต้องพิมพ์ซ้ำ
2. กดส่งคำขออนุมัติส่งผ่าน GitHub Issue (1 คลิก) หรือคัดลอกส่งใน Discord
3. แอดมินตรวจสอบและอนุมัติแอดมินจะตรวจสอบความถูกต้องก่อนอนุมัติขึ้นหน้าเว็บ

1. ข้อมูลพื้นฐานอาชีพ

🔗 สกิลที่สืบทอดมาอัตโนมัติ (ไม่ต้องพิมพ์ซ้ำ!)
เลือกอาชีพก่อนหน้าด้านบนเพื่อสืบทอดสกิลอัตโนมัติ

2. สกิลเฉพาะของอาชีพนี้ (หรือเลเวลอัปเกรดใหม่)

เพิ่มเฉพาะสกิลใหม่ หรือเลเวลใหม่ที่เพิ่งได้ในอาชีพนี้

3. ส่งข้อมูลให้แอดมินตรวจสอบและอนุมัติ
